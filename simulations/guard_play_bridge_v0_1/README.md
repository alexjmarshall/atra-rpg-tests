# Guard Play Bridge v0.1

Bounded behavioral micro-test of the two selected guard/Play bridges on the
governing provisional longsword engine.

- Scheitelhau versus Alber is specification-only and receives no active
  mechanic, price, or generic breaker modifier.
- Tutta cover-to-stretto is tested after a successful Basic Cross against an
  ordinary proactive Basic Cut at Wide measure.
- `CONTROL` is the current G1 bridge; `T0` and `T1` price the same learned
  continuation at 0 and 1 Spiritus.
- Skill is fixed at 14, starting Spiritus is 8 or 3, and the standard run uses
  640 mirrored fights per cell with balanced ordered starting guards.

Run from the repository root:

```powershell
python simulations/guard_play_bridge_v0_1/simulate.py
```

The script writes `reports/guard-play-bridge-v01-results.json` and
`reports/guard-play-bridge-v01-results.md`.
