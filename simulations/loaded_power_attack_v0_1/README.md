# Loaded / Power Attack v0.1

This directory contains an isolated PROVISIONAL experiment built on the
explicit Crossing/Bind state engine. It does not modify the canonical melee
packet, Play catalog, named-Guard roster, binary Parry procedure, or the active
repertoire of state creators.

Primary duel cells are FORCED-LOADED / POWER-ELIGIBLE and must be read as
UPPER-BOUND AVAILABILITY STRESS TESTS. Run:

```powershell
python simulations/loaded_power_attack_v0_1/simulate.py
```

The fixed-seed run writes the Markdown and JSON deliverables to `reports/`.
