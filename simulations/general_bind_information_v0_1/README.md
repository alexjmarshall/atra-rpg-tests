# General Bind Information Architecture v0.1

This isolated harness imports but does not modify the authoritative shared
longsword engine. It tests authored Hart/Weich on ordinary Basic Cross only,
paid Fühlen, a narrow attacker Bind Rejoinder for Duplieren/Mutieren, and a
scoped Counter-Wind against Duplieren.

Run from the repository root:

```powershell
python simulations/general_bind_information_v0_1/simulate.py
python -m unittest tests.test_general_bind_information_v01 -v
```

The analysis is exact enumeration and branch forcing; no Monte Carlo or
hand-authored utility constants are used.
