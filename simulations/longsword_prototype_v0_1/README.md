# Longsword mechanical prototype v0.1

This is a seeded, provisional Monte Carlo branch for six audited Longsword Plays. It does not modify canonical Play mechanics.

Run from the repository root:

```powershell
python simulations/longsword_prototype_v0_1/simulate.py
```

Inputs are in `data/prototypes/longsword-mechanical-v0.1.yaml`. Generated machine-readable results are `results.json`; the comparison report is `reports/longsword-mechanical-prototype-results.md`.

The model intentionally exposes its non-historical calibration assumptions. It is a comparative test of action/resolution chassis, not an empirical reconstruction of fencing frequency.
