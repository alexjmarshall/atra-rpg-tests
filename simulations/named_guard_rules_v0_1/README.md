# Named Guard Rules v0.1

This bounded experiment imports the shared governing provisional longsword
entry point. It does not copy the full combat engine.

- `G0`: current combat control, no named-guard mechanics.
- `G1`: named guards with intrinsic state, access/gates, and Donna's explicitly
  provisional Loaded/P1 harness assignment.
- `G2`: G1 plus the single adequately evidenced stress action,
  `Pflug Free Absetzen`, at 0 Spiritus and no learned-Play chain count.

Starting guards are balanced across all 16 ordered within-tradition pairs.
This is a simulation harness only; the starting-guard rule remains OPEN.

Run the full matrix with:

```powershell
python simulations/named_guard_rules_v0_1/simulate.py
```
