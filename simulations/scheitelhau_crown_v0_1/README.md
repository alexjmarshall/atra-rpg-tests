# Scheitelhau / Crown v0.1

Bounded German named-guard harness for the defended Scheitelhau-vs-Alber
sequence in Pseudo-Peter von Danzig, Cod.44.A.8, ff. 24v.3-25r.2.

- C1 represents Crown as ordinary Crossing plus a transient authored context.
- B1 and B3 compare learned-chain accounting only.
- The recommended B3 model leaves the entry Basic in chassis and makes
  `Sink Point Under Crown` the one learned continuation at 1 Spiritus.
- Generic Basic Cross is never Crown.
- The module does not run Named Guard Rules v0.2 or alter guard transitions.

Run:

```powershell
python simulations/scheitelhau_crown_v0_1/simulate.py
```
