# Crossing/Bind state-model v0.1

Run from the repository root:

```powershell
python simulations/crossing_bind_state_model_v0_1/simulate.py
```

The simulator writes `results.json`, `regression-summary.csv`, and
`reports/crossing-bind-state-model-v01-results.md`. The primary model contains
no random bind, pressure, contact-zone, or Close-Crossing generation. The
legacy harness is explanatory only.
