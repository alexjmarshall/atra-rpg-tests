# Durchwechseln–Schielhau state-model experiment

Run from the repository root:

```powershell
python simulations/longsword_prototype_v0_2/state_model_simulate.py
```

The script writes `state-model-results.json` and `reports/durchwechseln-schielhau-state-model-results.md`. All mechanics, state vocabulary, information policies, Parry subtypes, Schielhau resolutions, d6+1 damage, bind/close rates, and engagement abstractions are provisional.
