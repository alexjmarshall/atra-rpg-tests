# Bind Continuations v0.1

Run from the repository root with the workspace Python runtime:

```powershell
python simulations/bind_continuations_v0_1/simulate.py --trials 2000
```

The run writes `reports/bind-continuations-v01-results.md` and
`reports/bind-continuations-v01-results.json`. All new state creators are
deterministic test-harness fixtures and remain outside the active mirrored
combat repertoire.
